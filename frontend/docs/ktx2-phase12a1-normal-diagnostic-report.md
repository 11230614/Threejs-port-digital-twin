## 7. Mipmap 参考专项审核

### 7.1 三条流程与误差口径

**PASS：旧参考来源可复现。** 使用已有官方编码器 source-only 未压缩 DDS 路径，参数 `-dds -dds_format A8B8G8R8 -linear -mip_linear -mipmap -mip_filter kaiser -max_threads 4 -normal_map -mip_renorm`，重建出的全部 13 级 RGBA 与旧参考逐字节一致。未进行整图重复 KTX2 编码。排除旧参考来自错误 mip index、末级 padding 或另一套算法的假设。

另建立以下两条诊断参考，均保存每级输入/输出尺寸、文件哈希及数组：

- **A**：同一官方 source-only DDS 路径，去掉 normal_map/mip_renorm，仅对 Linear RGB 做 Kaiser 下采样；不使用颜色 Gamma。
- **B**：从原始 RGB 解码成 float32 向量，使用正权 2×2 area box 递归平均未归一化向量；每级另保存原始向量及仅对非零向量归一化的方向。零向量保留 NaN 并计数，不替换成默认法线。该流程避免中间 byte 量化，但没有解决 UV 岛之间混合，也不宣称它是生产环境唯一正确参考。

在相同线性权重、未量化/裁剪条件下，RGB 滤波再映射与向量滤波是仿射等价的，本轮保存了直接 box RGB 对照验证。因此不能将“对 RGB 滤波”一概称为错误。A/B 的差异还包含核函数、byte 量化、重归一化策略，不能把 B 对 KTX2 的差异全算成压缩损失。

实际编码误差必须比较 **旧同算法压缩前参考 → 实际解码**；独立 B 归一化参考 → 解码是另一种最终方向诊断。两者都保留，不能混成一个指标。

### 7.2 退化及官方 renorm 行为

官方源码 `encoder/basisu_enc.h` 的 `image::renormalize_normal_map()`：保留 (128,128,128)；向量长度 <0.077 时写入这个 sentinel；只有 `abs(length-1)>0.077` 才归一化。因此启用 mip_renorm 不代表每个像素都成为精确单位法线。该 sentinel 按 UNORM 解码长度约 0.006792，不是数学精确零。

本轮 `0.077` 仅用作与源码一致的**退化诊断界限，不是人为制定的质量合格阈值**。原始统计保留所有非零向量；另列稳定子集并明示剔除数。旧参考/实际解码任一低于此长度的全图剔除数为 L1=6,924、L2=375、L3=23，其余级别 0。

发现明确的压缩前抵消实例：B 的 L1 `(1399,176)` 来自源图 x=[2798,2800)、y=[352,354) 的四个像素：`(0,127,131)`、`(255,128,130)`、`(0,128,131)`、`(255,127,131)`。部分方向夹角约 177.304°，平均向量约 `(0,0,0.0254902)`，长度约 0.0254903。这个退化在任何 KTX2 压缩之前已经发生。

**PARTIAL：参考的生产正确性。** B 也会发生抵消，不能声称简单换成向量平均就消除问题；需要考虑源法线高频内容、atlas 邻接及 mip 策略。未经实际 GPU/原场景验证，不选择一种滤波核作为正式策略。

## 10. 八项结论与下一步边界

| 判断项 | 状态 | 结论 |
|---|---|---|
| Normal L0 压缩质量 | PARTIAL | 指标可复核；平均误差低，但有局部 95° 异常，未定义质量阈值，不判合格 |

| 负 Z 是否真实问题 | PARTIAL | 全为新增，1,654 点中心覆盖；不是天然非法，但不能作为未使用区排除 |
| Mipmap 参考可靠性 | PARTIAL | 旧链来源和编码误差参考可复现；近零参考方向退化、生产/GPU mip 等价性未解决 |
| 当前 UASTC 参数是否可接受 | PARTIAL | 不予质量通过；不能用全图 Mean 替代局部方向与渲染检查 |
| 是否需要重新编码 | PARTIAL | 若继续压缩 Normal，需验证新候选；局部 effort=4 改善不足以选定整图策略 |
