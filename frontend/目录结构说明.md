# 前端目录与文件说明

本文按当前前端源码和本次发布内容整理。路径均相对于 `frontend/`。仓库发布快照不包含 `tests/`、`node_modules/`、`dist/`、浏览器测试结果、本机环境文件或扫描临时脚本；这些不属于运行前端所需的源码目录。

## 顶层文件

| 路径 | 用途 |
| --- | --- |
| `.gitignore` | 忽略依赖目录、缓存、构建结果、浏览器结果和本机环境配置。 |
| `README.md` | 前端项目简介、开发命令和端口说明。 |
| `index.html` | Vite 页面入口，挂载 Vue 应用并加载 `src/main.ts`。 |
| `package.json` | 前端依赖及开发、构建、预览和类型检查命令。 |
| `package-lock.json` | 锁定 npm 依赖解析结果。 |
| `tsconfig.json` | TypeScript、Vue 单文件组件及严格类型检查配置。 |
| `vite.config.js` | Vue 插件、`@` 源码别名、GLB 资源识别及 `/api` 到 `127.0.0.1:3002` 的开发代理。 |
| `目录结构说明.md` | 本文件，说明发布版前端文件职责。 |

## 模型资源

模型由资产加载器按场景资产目录引用；文件本身是 Three.js 加载的 GLB 二进制资源。

| 路径 | 用途 |
| --- | --- |
| `model/AGV.glb` | AGV 车辆模型。 |
| `model/Crane.glb` | 港区起重设备模型。 |
| `model/battery_charger.glb` | 电池充电设施模型。 |
| `model/cc.glb` | 港区场景中的 `cc` 资产模型。 |
| `model/container_ship .glb` | 集装箱船模型（文件名中的空格为现有资源名的一部分）。 |
| `model/crane_harbour.glb` | 港口岸桥场景模型。 |
| `model/crane_harbour2.glb` | 第二套港口岸桥场景模型。 |
| `model/gantry_crane.glb` | 门式起重机模型。 |
| `model/jzx1.glb` | 集装箱模型变体 1。 |
| `model/jzx2.glb` | 集装箱模型变体 2。 |
| `model/jzx3.glb` | 集装箱模型变体 3。 |
| `model/small_cargo_ship.glb` | 小型货船模型。 |

## `src/` 应用源码

### 应用入口与运行时

| 路径 | 用途 |
| --- | --- |
| `src/main.ts` | 创建 Vue 应用、安装 Pinia 并挂载根组件。 |
| `src/App.vue` | 应用根页面，组织三维场景画布及业务面板。 |
| `src/style.css` | 全局布局、颜色、排版和组件样式。 |
| `src/app/PortRuntime.ts` | 创建、装配、启动及销毁港口场景 Runtime，协调帧循环和子系统生命周期。 |
| `src/scene/MainScene.ts` | 创建 Three.js 场景、相机、渲染器和场景级环境。 |
| `src/core/Clock.ts` | 提供帧更新使用的时间与 delta 时间。 |
| `src/core/EventBus.ts` | 应用内部事件的发布、订阅和取消订阅。 |
| `src/core/FrameObserver.ts` | 按优先级和频率调度逐帧更新回调。 |
| `src/three-ambient.d.ts` | 补充项目依赖或扩展 Three.js API 所需的类型声明。 |
| `src/vite-env.d.ts` | Vite 客户端环境变量和资源模块类型声明。 |
